# SALES-DATA-
🎯 Project Title: Diwali Sales Data Analysis
📌 Objective
The main objective of this project is to analyze the sales data during the Diwali festival season to:

Understand customer purchasing behavior

Identify top-selling products and profitable categories

Discover target demographics for marketing

Help retailers make informed business decisions for future Diwali seasons

🗂️ Dataset Description
Name: Diwali Sales Data.csv
Source: Kaggle – Diwali Sales Data (or create your own dataset)

🔢 Key Columns:
User_ID: Unique user identifier

Gender: Male/Female

Age Group: Age category of customer

State: Indian state

Marital_Status: 0 = Single, 1 = Married

Category: Product category (e.g., Clothing, Electronics)

Product_ID: Unique product identifier

Amount: Purchase amount in ₹

Occupation: Job profile of customer

🧰 Tools Used
Language: Python

IDE: Jupyter Notebook

Libraries: pandas, numpy, matplotlib, seaborn
